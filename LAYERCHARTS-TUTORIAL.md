# LayerChart Tutorial

LayerChart is a powerful library that supports various chart types and is compatible with both Svelte 4 and Svelte 5. This guide provides installation steps, configuration instructions, and a quick start example to help you get started.

---

## Installation

1. Install the required packages:

```bash
  npm install layerchart
```

2. (Optional) Install additional dependencies required for certain chart types:

```bash
  npm install d3-scale d3-array
```
